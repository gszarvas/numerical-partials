# numerical-partials
Code repository containing python source files used in my LSU Research Conference presentation: "Numerical Estimation of Partial Derivatives Using Python".

Contents:

composite.py: Numerical estimation formulas of composite derivatives for a function f(x(t), y(t))

first_derivative.py: Comparison of forward, backward, central finite difference schemes for a simple function f(x) 

first_partials.py: Numerical estimation formulas of first order partials f_x and f_y

gaussianCurve.py: Plots 3d Gaussian curve i.e. bell curve

graphs.py: Contains code for plotting several graphs examined in the report (some are commented out)

paraCurve.py: Plots the parametric curve f(x, y) = xy, x = sin(2t), y = cos(3t)

second_partials.py: Numerical estimation formulas of second order partials e.g. f_xy, f_xx, f_yy
